# Планировщик финансов v3

Модульная PWA для планирования личного бюджета.
Стек: Vanilla JavaScript (ES Modules), Vite, IndexedDB, Vitest.

Это **отдельный репозиторий**. Опубликованное приложение v2.1 не затрагивается.

## Требования

- Node.js ≥ 20
- npm ≥ 10

## Локальная разработка

```bash
npm install
npm run dev          # http://localhost:5173
